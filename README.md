# 🐢 My First Python Turtle Project

This is my first Python project uploaded to GitHub!

In this project, I used Python's **Turtle** module to create a simple blue square. The program opens a graphics window and uses a turtle object to draw four equal sides using a `for` loop.

## 🚀 What I Learned

Through this project, I practiced:

* Importing and using Python modules
* Working with the `turtle` module
* Creating and customizing a drawing window
* Using a `for` loop
* Understanding basic movement and angles
* Changing colors and pen size

## 💻 How It Works

The turtle moves forward **300 pixels** and turns **90 degrees** after each side. This process is repeated four times to create a square.
